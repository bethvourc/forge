# Docs Layout

Top-level product documents remain in the repository root for visibility:

- `AGENTS.md`
- `PROJECT_BRIEF.md`
- `ARCHITECTURE.md`

This `docs/` directory is reserved for implementation-facing material that can grow without
turning the repository root into a dumping ground, for example:

- architectural decision records
- subsystem design notes
- runtime flow documentation
- operator or contributor guides

Current documents:

- `IMPLEMENTATION_PLAN.md`: remaining end-to-end implementation work, organized into
  agent-sized tracks with acceptance criteria and validation commands.
